# VKCS KMS Terraform modules

A set of Terraform modules for `KMS` in VKCS.

## KeyManager Migrator

[KeyManager Migrator module](https://github.com/vk-cs/terraform-vkcs-kms/tree/master/modules/keymanager-migrator) makes it easy to migrate VKCS KeyManager secrets to VKCS KMS

## LockBox Migrator

[LockBox Migrator module](https://github.com/vk-cs/terraform-vkcs-kms/tree/master/modules/lockbox-migrator) makes it easy to migrate Yandex Cloud LockBox secrets to VKCS KMS

## Vault KVv1 Migrator

[Vault Migrator module](https://github.com/vk-cs/terraform-vkcs-kms/tree/master/modules/vault-kvv1-migrator) makes it easy to migrate HashiCorp Vault / OpenBao KVv1 secrets to VKCS KMS

## Vault KVv2 Migrator

[Vault Migrator module](https://github.com/vk-cs/terraform-vkcs-kms/tree/master/modules/vault-kvv2-migrator) makes it easy to migrate HashiCorp Vault / OpenBao KVv2 secrets to VKCS KMS
