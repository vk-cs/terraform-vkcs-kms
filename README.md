# VKCS KMS Terraform modules

A set of Terraform modules for `KMS` in VKCS.

## LockBox Migrator

[LockBox Migrator module](https://github.com/vk-cs/terraform-vkcs-kms/tree/master/modules/lockbox-migrator) makes it easy to migrate Yandex Cloud LockBox secrets to VKCS KMS

## KeyManager Migrator

[KeyManager Migrator module](https://github.com/vk-cs/terraform-vkcs-kms/tree/master/modules/keymanager-migrator) makes it easy to migrate VKCS KeyManager secrets to VKCS KMS
