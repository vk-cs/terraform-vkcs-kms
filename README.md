# VKCS KMS Terraform modules

A set of Terraform modules for `KMS` in VKCS.

## LockBox Migrator

This [module](./modules/lockbox-migrator/) makes it easy to migrate Yandex Cloud LockBox secrets to VKCS KMS

## KeyManager Migrator

This [module](./modules/keymanager-migrator/) makes it easy to migrate VKCS KeyManager secrets to VKCS KMS
